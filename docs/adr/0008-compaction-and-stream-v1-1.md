# ADR-0008: Context compaction and stream-JSON v1.1 (additive)

- **Status:** Accepted (2026-10-14)
- **Deciders:** project owner, on agent recommendation

## Context

Threads stop at the budget guard when context fills (MVP stance: fail loud, never
silently truncate). Production threads need compaction. The frozen stream-JSON v1
contract (ADR-0003, docs/stream-json.md) must not break: additive events only → v1.1.

## Decision

**Trigger:** estimated context ≥ `compaction.thresholdPercent` (settings key per
ADR-0006, default 90) of the resolved model's `contextWindow`. Estimation: last
provider-reported usage + chars/4 for local additions; conservative (compact early).

**Action:** replace the conversation PREFIX (everything older than the newest N=2
turns) with a summary generated by the SAME provider using a versioned prompt file
`prompts/compaction.md` (ADR-0002 property 2: prompts in-repo). The summary is stored
as a **dedicated `compaction` ThreadEvent** (never a synthetic assistant message —
replay must distinguish real turns from summaries). Fail-loud: summarization failure stops the run (exit 3, `provider_error` shape) with remediation; never silently truncate (a hard
cannot-shrink posture).

**Contract v1.1 (additive only; one atomic commit moves** docs/stream-json.md header+schema,
`STREAM_JSON_SCHEMA`/`void schema`, and the `stream-json.test.ts` event-type pins
**together):** one new stream event
`{"type":"compaction","summarized_turns":N,"kept_turns":M,"trigger":"threshold"}` and
one new ThreadEvent kind; every existing event's shape is byte-identical. `void schema`
bumps to v1.1; docs/stream-json.md gains the event with examples.

**Replay:** the fold materializes the compaction event as a USER message whose text
is `[compaction summary]\n<summary>` ahead of the kept turns (`ChatMessage` has no
system role mid-conversation); `replayFold` must gain an `assertNever`-style
exhaustiveness check while being touched — a new event kind must never compile clean
yet fold silently; the store's `THREAD_EVENT_TYPES` mirror (src/store/jsonl.ts) must
be updated atomically with the contracts union or `append` rejects the event; resume of a compacted thread is transparent to
providers.

**Manual path:** `void resume <id> --compact` forces a compaction before continuing
(P1 of the roadmap phasing); automatic threshold is P2 — the auto-trigger
lives in the ENGINE loop, checked before starting a new round (pinned so
`src/core/engine.ts` ownership is explicit).

## Consequences

Threads become effectively unbounded; token cost of summaries is user-visible in usage
events. Risk: summary quality loss is real and irreversible within a thread —
mitigations: kept-turn window is configurable (`compaction.keepTurns`, default 2), and
the original events remain in the JSONL (compaction is a view, not a rewrite — the log
is append-only and the fold chooses what to send). This ADR is the orchestrated
contracts change allowed to touch `src/contracts` additively; the standing reviewer
verifies additivity (no existing event field changed or removed).
